# Hélder Badim — Portfolio

A minimal, responsive Angular portfolio built around Hélder's frontend engineering work.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production build

```bash
npm run build
```

## Highlights

- Standalone Angular architecture with SSR configuration
- Responsive layout for mobile, tablet and desktop
- Light and dark themes with persisted preference
- Scroll-reveal and ambient CSS animations
- Reduced-motion support and semantic landmarks
- CV-derived experience, skills, education and contact links

Replace or extend the impact cards when public case studies become available.
